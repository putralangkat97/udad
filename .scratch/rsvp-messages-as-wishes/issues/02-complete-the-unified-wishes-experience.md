# 02: Complete the Unified Wishes Experience

**What to build:** Present RSVP-generated Wishes and direct Wishes through one moderation and public experience, so the couple can review all guest messages consistently and guests can read published Wishes.

**Blocked by:** 01: Capture RSVP Messages as Linked Pending Wishes

**Status:** done

- [x] Direct Wishes and RSVP-generated Wishes appear together in pending moderation.
- [x] Moderators can identify RSVP-generated Wishes and see attendance status and guest count where available.
- [x] Moderators can publish or reject either source using the existing Wish lifecycle.
- [x] Rejecting a Wish does not change its source RSVP.
- [x] The RSVP message field is labelled “Hope & prayer” with supporting copy for hopes, prayers, congratulations, and messages.
- [x] The public invitation renders published Wishes from both sources.
- [x] Public Wishes expose only the author's name and published message, never source, attendance, guest count, or recipient provenance.
- [x] Existing direct Wish submission behavior remains available and moderated.
- [x] Feature and frontend verification cover moderation context, public visibility, source privacy, and the revised RSVP field.
