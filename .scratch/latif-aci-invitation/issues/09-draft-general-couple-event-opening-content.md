# 09: Draft General, Couple, Event, and Opening Content

**What to build:** Let an authorized admin edit the invitation identity, couple
and parents, events, countdown, and opening quote as a draft while the current
published invitation remains unchanged for guests.

**Blocked by:** 08: Admin Authorization and Dashboard Shell

**Status:** ready-for-qa

      label, and opening quote/reference.
- [x] Edit bride and groom names, roles, parents, portraits, and frames.

- [x] Edit the countdown target and label.
